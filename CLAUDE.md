# Project Rules

## Git / GitHub

- **Never push code to GitHub without explicit permission from the user.** This includes `git push`, force pushes, pushing tags, and creating or updating PRs. Ask first, every time — permission for one push does not carry over to the next.
- **When permitted to push, always push to a separate branch** — never directly to `main` (or any other shared branch). Create a new, descriptively named feature branch (e.g. `feature/<short-description>` or `fix/<short-description>`) and push that; changes reach `main` only through a pull request.
- Upstream repo: https://github.com/AekamSidhu/Major-Project (we are a contributor).
